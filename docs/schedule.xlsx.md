Структура schedule.xlsx
Файл schedule.xlsx содержит три вкладки:
Вкладка "События"

Название: Название события (например, "Доклад про ИИ").
Анонс: Краткое описание (например, "Иван Петров расскажет о будущем ИИ").
Спикер: Имя спикера (например, "Иван Петров").
Зал: Название зала (например, "Зал 1").
Время начала: Дата и время (например, "2025-05-02T10:00").
Время конца: Дата и время (например, "2025-05-02T11:00").
Теги: Список тегов, разделённых запятыми (например, "ИИ,конференция").
Картинка: URL или путь к изображению (например, "https://example.com/image.jpg").
Имя опроса: Машинное имя опроса (например, "poll1").

Вкладка "Сервисные сообщения"

Название: Название сообщения (например, "Перерыв").
Описание: Текст сообщения (например, "Приглашаем на кофе!").
Время: Дата и время (например, "2025-05-02T12:00").
Картинка: URL или путь к изображению.
Срочно: Булево (True/False).
Без редактуры: Булево (True/False).
Теги: Список тегов.

Вкладка "Опросы"

Машинное имя: Уникальное имя опроса (например, "poll1").
Вопрос: Текст вопроса (например, "Понравился доклад?").
Варианты: Варианты ответа, разделённые запятыми (например, "Да,Нет,Не знаю").

Примечание: Файл должен находиться в /app/projects/<project_name>/schedule.xlsx.
